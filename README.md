# Microprocessor Design Course

📚 **Curso de Diseño de Microprocesadores de Propósito General**

Basado en el Capítulo 12 — *General-Purpose Microprocessors* del libro  
**"Digital Logic and Microprocessor Design with VHDL"** de Enoch O. Hwang

## 🌐 Ver la página del curso

👉 [**Abrir página del curso**](https://luis-acosta.github.io/microprocessor-design/)

## 📋 Contenido

- **Arquitectura de microprocesadores** — CPU = Unidad de Control + Ruta de Datos
- **Microprocesador EC-1** — 5 instrucciones, ISA de 8 bits, memoria ROM 16×8
- **Microprocesador EC-2** — 8 instrucciones, RAM 32×8, instrucciones aritméticas y saltos condicionales
- **Implementación VHDL completa** — Modelos conductual (FSMD) y estructural (FSM+D)
  - EC-1 Conductual
  - EC-2 Conductual
  - EC-2 Unidad de Control (FSM)
  - EC-2 Ruta de Datos (Datapath)
  - EC-2 Top-Level Estructural
- **Programas de ejemplo** — Countdown, GCD (Máximo Común Divisor)
- **Formato MIF** para inicialización de memoria
- **Problemas y ejercicios** del capítulo
- **Glosario de términos**
